# Comp Dossier

Brewhouses of the Hanse: a medium-heavy (~3.3) euro about Hanseatic League beer
production. Its standing comps — the games it wants to go toe-to-toe with — are
**Great Western Trail** and **Distilled**. Use those by default; swap or add
whatever the user names at runtime. The wider set below was developed for
contrast and is fair game when a specific comparison illuminates something.

For each face-off, resolve three things honestly: where Brewhouses **wins**,
where it **loses**, where it **draws**, and the blunt answer to *"why keep this
and shelve the comp?"* If Brewhouses loses a face-off, that's not a verdict —
it's an input to the forward path.

## Primary comps

**Great Western Trail (Pfister, 2016)** — the depth-pull benchmark.
Signature: a **player-built track** you loop while opponents reshape it, so the
puzzle is re-solved live, never memorized. Runs multiple charge/discharge
engines on different clocks (deck-thinned deliveries, the train line, building
placement) so one is always near release — it never goes flat. Deck-building
*inside* a board game. Loss is highly legible. This is the bar for "does
Brewhouses convert skill into a win, and can the player see why they lost."
Brewhouses must answer: do my subsystems interlock and stay live the way GWT's
do, or do they run in parallel without pressuring each other?

**Distilled (Hutton, 2023)** — the thematic neighbor and the cautionary comp.
Production-of-alcohol euro with a strong, legible theme and an
ingredients-to-product engine. Its draw is theme–mechanism fit plus the tactile
joy of building a batch; its knock from heavy players is that variance (card
market draws) can outweigh skill and the decision space isn't as deep as its
weight implies. The instructive contrast for Brewhouses: Distilled wins on
theme-charm and accessibility, and is *vulnerable* on depth/legible-loss.
Brewhouses' opening to differentiate is to out-*depth* Distilled while matching
its thematic warmth — i.e. be the Hanseatic beer game that also rewards mastery.
If Brewhouses is *less* deep than Distilled, that's a five-alarm finding.

## Wider contrast set (use when a specific point needs it)

- **Lisboa (Lacerda, 2017)** — depth pull at maximum density; regret machine,
  every card coupled 3–4 ways. The reference point for "is every decision
  carrying enough weight." Likely *heavier* than Brewhouses wants to be; useful
  as the ceiling, not the target.
- **Orléans (Stockhausen, 2014)** — bag-building; variance you author and take
  credit for. Reference for "is the randomness steerable, or does it just
  happen to the player."
- **Agricola (Rosenberg, 2007)** — worker placement; scarcity + feeding anxiety;
  forced breadth under scarcity. Reference for "does a single rule generate a
  whole decision economy" and "does scoring force uncomfortable breadth or
  reward clean specialization."
- **Viticulture (2013/2015)** — seasonal worker split; generous, swingy visitor
  combos = a *hope* engine. Reference for variety pull and weight-bridging. If
  Brewhouses leans on swingy cards, this is the comp for whether that's tuned
  for fun or for fairness.
- **Wingspan (2019)** — accelerating return with zero punishment; the
  illegible-loss ceiling. The anti-pattern reference: a heavy-ish game must not
  inherit Wingspan's "can't tell why I lost" if it wants the depth audience.
- **Obsession (2018)** — fantasy pull; reputation gating *is* social ascent.
  Reference for theme–engine fusion and the devoted-niche commercial shape —
  closest to Sean's stated "niche theme positioning" thesis.
- **Unconscious Mind (2024)** — comfort pull; frictionless compounding,
  near-zero interaction. Reference for the solo/cozy-heavy lane.

## The differentiation question

Brewhouses' thesis (per Sean) is **niche theme positioning** — the Hanseatic
beer setting is a real edge no major comp owns. But theme gets the first table;
it doesn't drive retention. So the face-off must separate two things:
1. **Does the theme give it a sellable hook the comps lack?** (Buyer's
   question — Brewhouses likely *wins* here vs GWT's generic Western and
   Distilled's broader spirits theme.)
2. **Does the system give it retention the comps have?** (Optimizer's question —
   this is where GWT is the bar and Distilled is the beatable target.)

A great answer to 1 with a weak answer to 2 is exactly the "secretly running on
variety pull" trap: it sells on theme, then needs expansions to stay alive. The
win condition is a strong answer to *both* — the niche hook *and* legible depth.
