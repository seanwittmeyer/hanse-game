# Comp Dossier

A comp face-off only teaches something if the comps are chosen deliberately.
Don't reach for the same two or three familiar titles by reflex — build the
set for the game actually in front of you.

## How to pick comps for any game

Look for three things, in this order:

1. **The primary comp** — the game already sitting in the exact shelf space
   (or Kickstarter-audience space) this game wants. Same weight, same general
   genre, already owns the customers you're trying to win. This is the bar:
   "does the game under review actually beat this on the axis that matters
   most" is the sharpest single question a review can answer.
2. **The thematic-neighbor / cautionary comp** — a game that shares theme,
   setting, or surface appeal but has a known, well-documented weakness (often
   variance outrunning skill, or a thin decision space under a heavy-looking
   shell). This comp exists to test whether the game under review repeats that
   specific mistake. Naming the mistake explicitly is the point.
3. **A small wider contrast set (2–4 games)** — chosen not for genre match but
   because each one is the clean reference exemplar for one specific axis the
   review needs to test. Pull from the library below, or add your own; the
   requirement is that each pick earns its place by illuminating something the
   primary and cautionary comps don't.

If the user names specific comps at runtime, use those — they know their
target shelf better than a default list does. If a title under review already
has a standing dossier below (e.g. Brewhouses), use it by default, but still
swap or add anything the user names.

For every face-off, resolve three things honestly: where the game under
review **wins**, where it **loses**, where it **draws**, and the blunt answer
to *"why keep this and shelve the comp?"* A loss isn't a verdict — it's an
input to the forward path.

## Wider contrast library

Tagged by what each one is the clean reference for, across the weight
spectrum — not just heavy euros. Reach for whichever axis the review actually
needs.

- **Lisboa (Lacerda, 2017)** — depth pull at maximum density; regret machine,
  every card coupled 3–4 ways, and its rubble mechanic is a rare case of a
  cost gate that's also the currency that grows your capacity — theme fused
  to mechanism, not skinned on. Reference for "is every decision carrying
  enough weight" and for what real theme-mechanism fusion looks like.
- **Great Western Trail (Pfister, 2016)** — a player-built track opponents
  keep reshaping, so the puzzle is re-solved live, never memorized; multiple
  charge/discharge engines on different clocks so one is always near release.
  Reference for "does skill convert into a legibly better result" and for
  subsystems that pressure each other instead of running in parallel.
- **Orléans (Stockhausen, 2014)** — bag-building; variance you author and take
  credit for. Reference for "is the randomness steerable, or does it just
  happen to the player."
- **Agricola (Rosenberg, 2007)** — worker placement; scarcity + feeding
  anxiety; forced breadth under scarcity. Reference for "does a single rule
  generate a whole decision economy" and "does scoring force uncomfortable
  breadth or reward clean specialization."
- **Viticulture (2013/2015)** — seasonal worker split; generous, swingy
  visitor-card combos = a *hope* engine. Reference for variety pull and
  weight-bridging, and for whether swingy cards are tuned for fun or for
  fairness.
- **Wingspan (2019)** — accelerating return with zero punishment; the
  illegible-loss ceiling. The anti-pattern reference: a game that markets
  itself as strategic must not inherit "can't tell why I lost" if it wants the
  depth audience to stick around past launch.
- **Obsession (2018)** — fantasy pull; reputation gating *is* social ascent.
  Reference for theme–engine fusion and the devoted-niche commercial shape.
- **Unconscious Mind (2024)** — comfort pull; frictionless compounding,
  near-zero interaction. Reference for the solo/cozy-heavy lane.
- **Azul (2017)** — a tiny rule set that still generates real tension through
  shared, contested resources. Reference for "does a light/family-weight game
  earn genuine decisions out of almost no rules overhead," and the bar for
  "elegant" as opposed to "thin."
- **Ticket to Ride (2004)** — the reference accessible-depth family bridge:
  a five-minute teach with a real route-blocking mind game underneath.
  Reference for "is the on-ramp actually open, and does the depth reward
  repeat play without punishing a first-timer."
- **Codenames / Just One** — pure social pull, ~zero systemic depth by
  design. Reference for what a game leaning entirely on social pull looks
  like when it's done on purpose, and the honest bar for party games: don't
  grade these against the legible-loss test, grade them on whether they
  reliably manufacture their social moment with a new table.

## Example: Brewhouses of the Hanse (standing dossier)

Brewhouses of the Hanse: a medium-heavy (~3.3) euro about Hanseatic League
beer production. Its standing comps — the games it wants to go toe-to-toe
with — are **Great Western Trail** and **Distilled**. Use those by default for
this specific title; swap or add whatever the user names at runtime.

**Great Western Trail (Pfister, 2016)** — the depth-pull benchmark (see
library entry above for the signature mechanism). This is the bar for "does
Brewhouses convert skill into a win, and can the player see why they lost."
Brewhouses must answer: do my subsystems interlock and stay live the way
GWT's do, or do they run in parallel without pressuring each other?

**Distilled (Hutton, 2023)** — the thematic neighbor and the cautionary comp.
Production-of-alcohol euro with a strong, legible theme and an
ingredients-to-product engine. Its draw is theme–mechanism fit plus the
tactile joy of building a batch; its knock from heavy players is that
variance (card market draws) can outweigh skill and the decision space isn't
as deep as its weight implies. The instructive contrast: Distilled wins on
theme-charm and accessibility, and is *vulnerable* on depth/legible-loss.
Brewhouses' opening to differentiate is to out-depth Distilled while matching
its thematic warmth — be the Hanseatic beer game that also rewards mastery.
If Brewhouses is *less* deep than Distilled, that's a five-alarm finding.

Lisboa is the useful ceiling reference for Brewhouses specifically (likely
heavier than Brewhouses wants to be — a target for "how coupled can a
decision get," not a weight to match).

**The differentiation question, specific to Brewhouses:** its thesis (per
Sean) is niche theme positioning — the Hanseatic beer setting is a real edge
no major comp owns. But theme gets the first table; it doesn't drive
retention. Separate two things: (1) does the theme give it a sellable hook
the comps lack — Brewhouses likely wins this vs. GWT's generic Western and
Distilled's broader spirits theme; (2) does the system give it retention the
comps have — this is where GWT is the bar and Distilled is the beatable
target. A strong answer to (1) with a weak answer to (2) is the "secretly
running on variety pull" trap: it sells on theme, then needs expansions to
stay alive. The win condition is a strong answer to both.

## Building a dossier for a new title

When reviewing a Waterworks title without a standing dossier here (PDX, Red
Dog Junction, Alpenglow, Tembo Tiles, or a new prototype), or an outside
submission, build one fresh using the methodology above and note it in the
review — don't reach for Brewhouses' comps by default just because they're
already written down. If a dossier stabilizes across a few reviews of the
same title, it's worth adding to this file the way Brewhouses' was.
