# Archive

The root of the repo is always the **working directory for the live version**. This folder
holds everything before v8.0 that is worth keeping at hand; older builds (v0.16.1 · v2.9.1 ·
the v3 exploration), the v0–v4 records and studies, and every sim corpus are preserved in
**git history**.

| What | Why it's here |
|---|---|
| `v5/` | The frozen, playable **v5.8 “Pay the Second”** build (`KEY hanse-v58`) — its pages, docs and its own `playtests/` battery. |
| `v6/` | The frozen, playable **v6.5b “work the station”** build (`KEY hanse-v65b`), with `V6-PLAN.md`, the v6 program. |
| `records/DESIGN-HISTORY-pre-v8.md` | The design history before v8.0: the v5.7 architecture as it stood, the v0.1 → v7.0b change log, the parking lot, the pre-v8 open watches, the v5.3b glossary, and the charter's v5–v7 digest. |
| `records/COMPONENTS-pre-v8.md` | The v5.8 component body with every kit delta through v7.0b. |
| `records/STYLE-pre-v8.md` | The pre-v8 registry entries: the v5 noun and verb tables, the applied decisions, the v6 and v7 term families. |
| `records/ICON-ROUNDS.md` | The 2026-08 icon program: its rounds of designer review and the Lucide → PNG inventory it worked from. |
| `records/V7-PLAN.md` · `records/GATEKEEPER-v70b.md` | The v7 program (the v6.5b post-mortem, the ten directives, the v7 sheet) and the first oracle read of v7.0b. v7.0b was not archived as a build ("it was a bust"); it is git history. |
| `records/V5-DECISIONS.md` and the per-letter records (`V5-OPEN-WHARF` · `V51-WHARF-HANDS` · `V52-GROUNDWORK` · `V53-BOURSE` · `V54-THE-TIDE` · `V55-FOUR-HANDS` · `V56-THE-GLUT` · `V57-PLAIN-SAIL` · `V58-PAY-THE-SECOND`) | The designer's v5 decision records. |
| `records/GATEKEEPER-v51` · `RIDER-SCOPE-AB-v51` · `ORACLE-STUDY-v51r` · `ORACLE-STUDY-v52` · `BALANCE-PROPOSAL-v52` | The v5 studies. |
| `index-rulebook.html` · `learn.html` | The retired Rulebook & Components web page and the learn-to-play primer. |

Also in git (branches, not folders): `archive/main-v0.16.1` (the full v0.16.1 repo state)
and `archive/option-b-inland` (the rolled-back Inland Road prototype).

**Reference only — never edit archived files.** The canonical, evolving surfaces live at the
repo root; the standing rule (fix every surface together, mirror = `play.html`) applies to
root only.
